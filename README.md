# English for IT — نسخة الآيفون (PWA أوفلاين)

## الرفع على GitHub Pages (مجاني، بدون Mac)
1. أنشئ Repository جديد على GitHub (**Public**).
2. ارفع **كل ملفات هذا المجلد** مباشرة في جذر المستودع (index.html, app.js, data.js, style.css, sw.js, manifest.webmanifest, والأيقونات).
3. من Settings → Pages: Source = **Deploy from a branch** ، Branch = **main** ، Folder = **/ (root)** ثم Save.
4. بعد دقيقة يظهر الرابط: `https://USERNAME.github.io/REPO/`

## التثبيت على الآيفون
1. افتح الرابط في **Safari** (مش Chrome).
2. اضغط زر المشاركة ⬆️ ← **Add to Home Screen (إضافة إلى الشاشة الرئيسية)**.
3. افتح التطبيق من الشاشة الرئيسية **مرة واحدة وأنت متصل بالإنترنت** عشان يتحمّل كل شيء، بعدها يشتغل أوفلاين بالكامل.

ملاحظة: تقدمك محفوظ على الجهاز نفسه. لا تحذف التطبيق ولا تمسح بيانات Safari.
